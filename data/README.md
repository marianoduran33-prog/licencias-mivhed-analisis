# Datos

**Fuente:** [Licencias emitidas por el MIVHED, 2022–2026](https://datos.gob.do/dataset/licencias-emitidas) —
Portal de Datos Abiertos de la República Dominicana. Publicado por el Ministerio de la Vivienda, Hábitat y
Edificaciones (MIVHED). Licencia **ODbL** (Open Database License).

Descarga directa: https://mivhed.gob.do/wp-content/uploads/2026/07/Licencias-emitidas-2022-2026-.csv

Coloque el archivo en esta carpeta con un nombre que empiece por `Licencias` (CSV o Excel). Si la carpeta está
vacía, el notebook intenta descargarlo de la fuente oficial.

El archivo trae dos filas decorativas antes de los encabezados; el notebook las omite automáticamente.
